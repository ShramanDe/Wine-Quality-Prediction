
# 🍷 Wine Quality Prediction using Machine Learning

## 📌 Overview
This project focuses on **predictive modeling for food quality enhancement**, using the **Wine Quality Dataset** as a case study.  
Machine learning models are developed to predict wine quality based on physicochemical properties.

This project demonstrates **end-to-end data science workflow** including data preprocessing, exploratory analysis, model training, and evaluation.

---

## 🎯 Objectives
- Understand key chemical factors influencing wine quality
- Perform exploratory data analysis (EDA)
- Build and compare multiple machine learning models
- Evaluate models using appropriate performance metrics

---

## 🧠 Models Implemented
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (if applicable)

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Libraries:** NumPy, Pandas, Scikit-learn, Matplotlib, Seaborn  
- **Environment:** Jupyter Notebook  

---

## 📊 Dataset
- **Source:** UCI Machine Learning Repository  
- **Data Type:** Tabular (Physicochemical measurements of wine)

---

## 🚀 How to Run
```bash
git clone https://github.com/ShramanDe/Wine-Quality-Prediction.git

jupyter notebook
```

## 📈 Results
The project demonstrates that ensemble-based models outperform simpler linear models, highlighting the importance of non-linear relationships in wine quality prediction.
